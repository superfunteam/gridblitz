# Brand assets

The social card was created with the built-in image generation tool. The original is retained in `og-source.png`; `npm run assets` downsizes it to `dist/og-image.png` at 1200×630. The SVG icon source extends the existing lime-and-black lightning mark.

## Social image prompt

Use case: ads-marketing.
Asset type: a finished Open Graph social-sharing card for the existing mobile puzzle game Grid Blitz.
Create a polished, bold graphic at exactly 1200 x 630 pixels (landscape 1.905:1). Match the game’s identity: electric lime #d4fa44, near-black #252623, warm-white #fafbf7 and ivory Scrabble-like letter tiles, crisp black outlines and tactile raised edges. No photographic background.
Composition: large confident black sans-serif title "GRID BLITZ" in the left half, small lime lightning-bolt app mark near the title, and below it the exact two-line sentence "A little grid." / "A big brain break." On the right, a chunky 3x3 puzzle grid shown almost straight-on with slightly dimensional tiles, black tray and these exact letters and little corner numbers: top row B1 O2 P3; middle row E2 A3 R1; bottom row D3 R1 Y2. The center A3 tile is vivid lime, the other eight tiles are warm ivory. Minimal geometric decoration, generous breathing room, very readable at thumbnail size, all important content inside a 50px safe margin. Small footer text "gridblitz.superfun.games". No browser chrome, no buttons, no other text, no watermark.
